# \#  Doctor–Patient Microservices Platform

# 

# A cloud-native healthcare backend built using \*\*Spring Boot Microservices\*\*, demonstrating real-world service discovery, centralized configuration, API gateway routing, and containerized deployment.

# 

# ---

# 

# \## Project Overview

# 

# The \*\*Doctor–Patient Microservices Platform\*\* is a distributed system that simulates a hospital workflow where doctors, patients, and appointments are managed as independent microservices.

# 

# The system follows modern microservices principles:

# \- Loose coupling

# \- Dynamic service discovery

# \- Centralized configuration

# \- Containerized deployment

# 

# All services communicate dynamically without hard-coded URLs, making the system scalable and production-ready.
